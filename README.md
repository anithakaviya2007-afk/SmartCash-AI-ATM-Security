 # SmartCash AI - ATM Monitoring and Security

## Project Overview
SmartCash AI is an interactive ATM fleet monitoring and security platform designed to improve ATM availability, cash management, and user safety.

## Technology Stack
- React
- TypeScript
- Vite
- GitHub

## Main Features
- ATM cash-level monitoring
- Low-cash alerts
- ATM status dashboard
- Cash depletion forecasting concept
- Biometric authentication workflow
- Emergency freeze workflow
- Notifications and digital receipt workflow

Some features use simulated data. Backend integration and machine-learning implementation are planned.

## Installation

Install Node.js, then run:

```bash
npm install
npm run dev
```

To build the project:

```bash
npm run build
```
